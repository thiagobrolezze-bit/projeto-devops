
# Projeto DevOps

API simples de gerenciamento de tarefas desenvolvida em Python utilizando Flask.

## Funcionalidades

- Listar tarefas
- Buscar tarefa por ID
- Criar tarefa
- Excluir tarefa

## Tecnologias utilizadas

- Python
- Flask
- Git
- GitHub

## Como executar

### 1. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 2. Executar a aplicação

```bash
python app.py
```

### 3. Acessar

Abra no navegador:

http://127.0.0.1:5000

## Como executar os testes

```bash
python -m unittest test_app.py
```
